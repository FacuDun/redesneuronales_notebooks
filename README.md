# Repositorio de notebooks sobre redes neuronales

Repositorio donde publico proyectos personales relacionados con redes neuronales, organizados por categoría.

## Categorías

### [`Implementaciones desde 0`](./implementaciones-desde-cero)

Modelos de redes neuronales clásicos implementados desde cero, sin frameworks como PyTorch o TensorFlow, solo librerías básicas (NumPy, Pandas, Matplotlib). El objetivo es didáctico: Entender el funcionamiento interno de cada arquitectura antes de usar herramientas de alto nivel.

Trabajos incluidos:

- [`Red SOM`](./implementaciones-desde-cero/red-som/) — Mapas autoorganizados para clustering no supervisado.

Cada notebook tiene su propio README con más detalles sobre el trabajo.
